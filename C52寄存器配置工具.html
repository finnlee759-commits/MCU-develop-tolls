② 定时器 / 计数器 (T0、T1、T2)

定时器模式速查：模式0 13位(最大8192)；模式1 16位(最大65536，最常用)；模式2 8位自动重装(最大256，常用于波特率)；模式3 仅 T0 拆为两个8位(TH0 借用 TR1/TF1)。
机器周期 = 12 / fosc（12T 模式）。11.0592MHz → 1.085μs；12MHz → 1μs。初值 = 最大计数值 − 定时时间/机器周期。

③ 串行通信 (UART)

  

    
串口工作方式表
SCON 的 SM0 SM1

    
SM0 SM1方式功能波特率常用 SCON 值

    
    
0 00同步移位寄存器（扩展 74HC164/165）fosc/12 固定0x00 / 0x10

    
0 1110位异步 UART（1起始+8数据+1停止）— 最常用可变：T1 或 T2 溢出率决定0x50 (允许接收)

    
1 0211位异步（第9位 TB8/RB8，可作奇偶校验/多机）fosc/64 (SMOD=0) 或 fosc/32 (SMOD=1)0x90

    
1 1311位异步，同方式2可变，同方式10xD0

    

    
波特率公式（方式1/3）：T1 模式2 → Baud = 2^SMOD × fosc / (32 × 12 × (256 − TH1))；T2 → Baud = fosc / (32 × (65536 − RCAP2))。
串口通信请用 11.0592MHz 晶振，12MHz 下 9600 误差约 8.5%，通信不可靠。发送：写 SBUF → 等 TI=1 → 软件清 TI；接收：RI=1 → 读 SBUF → 软件清 RI。

④ 并行 I/O 口 (P0 ~ P4)

  

    
I/O 口结构与第二功能

    
端口结构第二功能注意事项

    
    
P0 (80H)开漏输出，无内部上拉外部总线时作 AD0~AD7 地址/数据复用作普通 I/O 必须外接 10kΩ 上拉电阻(排阻)；常用于 LCD1602/12864 数据线、数码管段选

    
P1 (90H)准双向口，内部上拉P1.0 = T2 (T2 计数输入/时钟输出)，P1.1 = T2EX (捕获/重装触发)最“干净”的通用 I/O

    
P2 (A0H)准双向口，内部上拉外部总线时作高8位地址 A8~A15常用于 74HC138 位选、LCD 控制线

    
P3 (B0H)准双向口，内部上拉P3.0 RXD · P3.1 TXD · P3.2 INT0 · P3.3 INT1 · P3.4 T0 · P3.5 T1 · P3.6 WR · P3.7 RD用第二功能时该位须保持写“1”

    
P4 (E8H) STC准双向口P4.2 = INT3，P4.3 = INT2仅 PLCC44/LQFP44 封装有；需自行 sfr P4 = 0xE8;

    

    
⚠ 准双向口读引脚前必须先写 1（如 P1 = 0xFF; key = P1;）。准双向口输出高电平驱动能力弱（几十 μA），驱动 LED 推荐“低电平点亮”（灌电流）。

    并行总线访问外部器件：#include <absacc.h> 后用 XBYTE[0x7FFF] = dat; 自动产生 WR/RD 时序。
